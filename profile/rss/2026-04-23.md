## Fields exposed by the RSS feed (per entry)

- `<yt:videoId>` → canonical 11-char ID
- `<yt:channelId>` → owner channel (sanity-check boundary)
- `<title>` → video title (HTML entities decoded)
- `<published>` → **ISO 8601 timestamp** of first publication (this is what makes RSS valuable — pins exact dates the /videos tab can only give as relative "N months ago")
- `<updated>` → ISO 8601 of last metadata change
- `<link rel="alternate" href="…">` → watch URL, **form tells us `/shorts/` vs `/watch?v=`** (short vs. long-form at parse time)
- `<media:description>` → creator description text (empty on many shorts)
- `<media:thumbnail url="…" width="…" height="…">` → i3.ytimg.com hqdefault
- `<media:statistics views="…"/>` → **exact view count at snapshot time** (no rounding)
- `<media:starRating count="…" average="…"/>` → like-count proxy (always 5.00 avg for public channels since YouTube removed dislikes; `count` = total votes)
- `<media:content url="…" type="…" width="…" height="…">` → legacy Flash embed URL (ignore)
