## Description

How to assemble the mechanical structures in the SCUTTLE Robot v3.0 design.  View each subassembly, the steps for combining parts, where to place the screws, and how to orient each component.  The main assemblies are
1) a rolling chassis with free moving casters
2) DIN rail with brackets for all electronics
3) wheel assembly, with motor, belt, and pulleys


[Tips for Builders]
If you are building SCUTTLE for the first time, please find Assembly Guide PDF at scuttlerobot.org.
https://www.scuttlerobot.org/resource/guide/assembly-parts-guide/
We recommend replaying this video and pause where you need.  Use the Assembly Guide PDF for details on each subassembly.  The PDF also has further links to videos & documentation.
