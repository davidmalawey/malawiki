## Description

How to assign a revision number, and automatically add text to your printed part design.  The text deboss feature (cut extrude) will update when you adjust the revision number.

Font: DS ISO
Height: 6mm
Class: Bold
Orientation: readable*
Location: offset 6mm from base
Depth: 0.5mm

Make a property:
File ► Properties ► Custom (tab) ► Property Name ► Revision

* choose the orientation such that during a print, you can see the revision number.  This offers a verification A) the print started in the right direction and B) you didn't mix up the file versions.
