## Description

This video shows in SOLIDWORKS 2019 how to:
~ create a new part configuration
~ switch views to different configurations
~ assign a global variable to a pattern
~ change the pattern quantity based on configuration
~ edit global variables for each configuration

In large assemblies, you can reduce complexity by making parts with patterns instead of subassemblies with many parts.
