# Leveraging physical testing

## Definition

Recurring "no FEA can tell you that — only testing can" theme. Physical testing reveals failure modes simulation misses (anti-ooze plate design, real-world tolerance drift, contamination). Pairs with [[concepts/finite-element-analysis|FEA]] as a check, not a substitute.
