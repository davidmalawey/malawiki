# CAD configurations

## Definition

Single CAD file storing multiple sizes/variants of a part via configurations and global variables. Switching configuration regenerates the same model at a different size — no separate file per variant. SOLIDWORKS's first-class implementation; equivalents exist in most modern CAD.
