# Poka-yoke

## Definition

Japanese mistake-proofing principle from Toyota Production System — design a part so it physically cannot be assembled wrong. The [[entities/tools/flashforge-creator-pro2|Creator Pro 2]]'s asymmetric extruder mounts are an explicit poka-yoke instance: you can only put each extruder back in one orientation.
