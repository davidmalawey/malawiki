# GP1 as debug port

## Definition

On the [[entities/tools/beaglebone-blue|BeagleBone Blue]], the GP1 connector's two outputs mirror the on-board green and red user LEDs. Wiring first prototypes to GP1 means the LEDs already display GPIO state without scope or multimeter.
