# Function overlap with module

## Definition

Sub-concept of [[concepts/leverage-incumbent-engineering|leverage-incumbent-engineering]]: when you find an off-the-shelf module whose function overlaps your need, design *into* its interfaces rather than around it. The closer the overlap, the more engineering you skip.
