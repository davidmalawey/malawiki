# Hardware enshittification

## Definition

Once a hardware product holds market-leader position in a steady-size market, design goals shift from end-user value to per-unit cost reduction. Wall thickness shrinks, fiber count drops, alloys swap to whatever passes the minimum stress test — the user experience degrades each generation.
