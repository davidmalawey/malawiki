# Runtime-tunable parameters

## Definition

Reading control gains from a flat file (e.g. `kp.txt`) written by an external UI ([[entities/tools/node-red|Node-RED]] slider) so values can be tuned without restarting the program. Inverse of [[concepts/telemetry-via-flat-files|telemetry-via-flat-files]] — UI writes, runtime reads.
