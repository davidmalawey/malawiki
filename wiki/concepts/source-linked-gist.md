# Source-linked gist

## Definition

Pasting the [[entities/tools/github-gist|Gist]] URL of an exported [[entities/tools/node-red|Node-RED]] flow as a comment in the Python source that produces the telemetry — so the matching dashboard is always findable from the code that generates its inputs.
