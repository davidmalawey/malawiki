# Heat-set insert installation

## Definition

Process of permanently embedding a brass [[entities/tools/threaded-insert|threaded insert]] into an FDM-printed plastic part by melting the surrounding plastic with a [[entities/tools/soldering-iron|soldering iron]] as the insert is pressed home. The result is a screw-friendly, repeatedly-removable thread in a part that would otherwise be limited to self-tapping fasteners.
