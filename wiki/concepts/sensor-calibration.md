# Sensor calibration

## Definition

Spinning a sensor through its operating range to capture min/max readings, then rescaling and centering so the runtime output spans a known interval (e.g. -1 to +1). Demonstrated for the [[entities/tools/mpu9250|MPU-9250]] magnetometer in SCUTTLE's compass video.
