# Manual feature recognition

## Definition

Walking SolidWorks's "Recognize Features" tool through an imported [[concepts/cad-configurations|STEP/IGES]] file feature-by-feature so the resulting tree is parametric and editable, instead of accepting an opaque dumb-body. The slow-but-controllable alternative to fully-automatic recognition.
