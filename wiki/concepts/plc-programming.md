# PLC programming

## Definition

Authoring control logic for a Programmable Logic Controller. In David's tutorial, this is done in [[entities/brands/automation-direct|AutomationDirect]]'s [[entities/tools/productivity-blocks|Productivity Blocks]] graphical environment, which exports to Arduino-compatible C++ for the [[entities/tools/p1am-100|P1AM-100]].
