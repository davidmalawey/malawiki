# Node-RED flow export / import

## Definition

Round-trip workflow for sharing [[entities/tools/node-red|Node-RED]] dashboards: top-right menu → Export → Clipboard (Formatted) → paste into a public [[entities/tools/github-gist|Gist]]; on the receiving instance, Import → Clipboard → New Flow.
