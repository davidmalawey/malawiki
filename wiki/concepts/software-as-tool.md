# Software as tool

## Definition

David's framing: software went from a discipline to a tool — like a calculator or Excel — that every engineer now uses. Combined with software-that-writes-software (smartphone automations, codeless platforms), it explains why "software engineer" dissolved as a standalone US Bureau of Labor Statistics category.
