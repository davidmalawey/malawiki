# Clip-before-power rule

## Definition

When connecting a load via alligator clips and a power source via [[entities/tools/anderson-connector|Anderson]] plugs, attach the clips to the load *first*, then plug power in. Reverses the failure mode where a live clip touches metal during attachment.
