# Feature-tree naming

## Definition

Discipline of explicitly naming bodies, features, and dimensions in a CAD feature tree (e.g., SolidWorks F2-rename) before splitting or modifying so the software preserves identity and future collaborators can read intent. Critical for parametric models that get revisited years later.
