# Global-variable-driven pattern

## Definition

Driving a SolidWorks pattern's instance count and spacing from global variables (`Hole Count`, `Hole Pitch`) so a single [[concepts/cad-configurations|configuration]] table generates all the variants. Foundation for the [[concepts/parts-library|parts library]] pattern.
