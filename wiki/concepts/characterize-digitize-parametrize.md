# Characterize → digitize → parametrize

## Definition

David's three-step path to a parametric model. Characterize the part with calipers and observation; digitize it as a faithful CAD model with measured dimensions; parametrize by replacing hard dimensions with named variables and relational constraints. Worked example: reverse-engineering a 1/4-20 ball-mount in SOLIDWORKS.
