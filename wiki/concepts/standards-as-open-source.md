# Standards as open source

## Definition

Repeated thesis across two 2024 essays: shared interfaces *are* the open-source layer. USB, NPT, 18650, DIN-rail, T-slot — once an interface is standard, every part that meets it is interoperable. Open-source hardware doesn't require open files; it requires open interfaces.
