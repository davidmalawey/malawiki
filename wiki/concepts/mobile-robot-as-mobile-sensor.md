# Mobile robot as mobile sensor

## Definition

Paradigm shift David proposes: stop thinking about the mobile robot as a thing that does work, and start thinking about it as a thing that carries a sensor through space. Reframes scoping conversations around what data the customer needs, not what manipulator the customer wants.
