## Overview

A 7:49 productivity tutorial showing David's workflow for producing clean, reusable component graphics in [draw.io](https://draw.io) wiring/system diagrams. Covers iOS auto-background-removal in the Photos app, Imgur cloud hosting, PowerPoint's Remove Background tool for screenshots, custom connection points, and exporting a shared scratchpad library so a whole team can reuse the same component icons.

## Key takeaways

- iOS Photos can auto-extract a subject from a photo (press-and-hold > Share > Save Image) — instant transparent PNG of any sensor or component on your bench.
- Upload to Imgur and share the link — image is now usable from anywhere; in draw.io scratchpad use Add Images and paste the URL to keep file size small.
- For product images you don't have on hand: snip from Amazon with **lots of margin**, paste into PowerPoint, click **Remove Background**. Tight crops confuse the algorithm — large bounding boxes do not.
- In draw.io: drag image into the scratchpad, name it, then right-click > Edit Connection Points to drop terminal locations directly on the image. Arrows can be sent to back so they appear to plug into terminals.
- Export the whole scratchpad library as a file and share with teammates — everyone gets the same component icons across diagrams.
- PowerPoint can save the cleaned image as PNG (Save as Picture) for permanent reuse.
