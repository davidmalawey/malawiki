# SCUTTLE servo arm v1

Two-joint, low-cost servo arm built from [[entities/materials/pvc|PVC]], 3D prints, [[entities/tools/hobby-servo|hobby servos]], and 608 skateboard bearings. CAD on [[entities/brands/grabcad|GrabCAD]] as `servoArm-v1.1`; STLs on GitHub at MXET/SCUTTLE/hardware/CAD/servoArm. 150 mm joint-to-joint reach; optional hockey-puck counterweight (172 g per puck, stackable 1-4) reduces servo torque demand.
