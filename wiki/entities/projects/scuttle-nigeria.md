# SCUTTLE Nigeria

Africa node of [[entities/projects/scuttle-robot|SCUTTLE Robotics]], hosted at FUTO in Owerri/Lagos and led by [[entities/people/gozie-nzebuka|Dr. Nzebuka]]. Built up from roughly half the typical lab-checkbox starting point including a custom solar+battery 24-hour power system. First build is a documented 3D-printer extruder. URL: scuttle-ng.vercel.app.
