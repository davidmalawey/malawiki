# Entities

People, tools, materials, brands, projects, and places referenced across videos. Each subtype gets its own folder; folders are created on demand.

```
entities/
  people/     # David, guests, referenced figures
  tools/      # specific tools used or discussed
  materials/  # wood, metal, resin, adhesive, etc.
  brands/     # manufacturers, suppliers
  projects/   # specific builds / creations featured
  places/     # workshops, venues, shops
```

See `CLAUDE.md` at the project root for the entity page template and frontmatter spec.
