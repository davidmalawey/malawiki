# Arduino MQTT client library

Arduino C++ library that lets ESP8266/ESP32 sketches connect to an [[concepts/mqtt|MQTT]] broker, publish, and subscribe. David's video walks through setting (or auto-generating) the client ID — a hidden gotcha when running multiple ESP8266 nodes against the same broker.
