# VS Code

Visual Studio Code editor with the SFTP extension. Lets SCUTTLE software be edited locally on a PC and auto-synced to the robot's [[entities/brands/raspberry-pi|Raspberry Pi]] or [[entities/tools/beaglebone-blue|BeagleBone Blue]] over SSH — replacing the older browser-based [[entities/tools/cloud9|Cloud9]] workflow.
