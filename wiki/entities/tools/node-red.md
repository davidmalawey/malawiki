# Node-RED

Flow-based browser GUI for wiring IoT devices, APIs, and online services into pipelines. SCUTTLE uses it as a telemetry dashboard, live-tuning UI for control gains, MQTT bridge, and gamepad-axis visualizer. Flows are exported as JSON and shared as [[entities/tools/github-gist|GitHub Gists]].
