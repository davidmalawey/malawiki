# Gamepad

Generic wireless game controller (Xbox-style) used as the manual-drive input for SCUTTLE. Axes are read via Python and either drive motors directly or get plotted in [[entities/tools/node-red|Node-RED]] for tuning. Recurs across SCUTTLE drive-control and IoT demos.
