# CBA power meter

[[entities/brands/west-mountain-radio|West Mountain Radio]] Computerized Battery Analyzer V5. USB-to-PC, free software. Performs automated discharge tests (cutoff voltage + target amps, reports total Ah/Wh) and charge-monitor tests (logs voltage only, separate ammeter required). Held in the [[entities/places/texas-am-lab|MXET department]] for student checkout.
