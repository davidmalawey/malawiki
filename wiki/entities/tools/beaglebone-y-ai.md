# BeagleBone Y-AI

AI-capable single-board computer from BeagleBone, similar to Raspberry Pi but oriented at advanced Linux/embedded users; being integrated into SCUTTLE. Distinct from the earlier [[entities/tools/beaglebone-blue|BeagleBone Blue]] used through 2019-2020. Several 2019-2020 SCUTTLE videos reference this slug as a stand-in for the Blue board — those references will be re-pointed in a future lint pass.
